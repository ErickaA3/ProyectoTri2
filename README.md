# 🌟 POLARIS

**AI-Powered Educational Platform**

Polaris is an AI-powered study platform that transforms raw material into interactive learning resources — flashcards, visual schemas, quizzes, expert exams, and structured summaries — all generated by AI. A full gamification engine with XP, levels, coins, streaks, daily missions, and weekly objectives keeps students engaged.

> Object-Oriented Programming — Final Project  
> Universidad Invenio · Information and Communication Technologies  
> March 2026

---

## 🚀 Features

- **Study Tools** — Upload text or files (PDF, DOCX, DOC, PPTX, TXT) and generate 5 types of AI-powered content
- **Gamification** — XP, 10 levels with animated profile frames, coins, streaks with shields, daily missions, weekly objectives
- **Virtual Shop** — Spend earned coins on animated backgrounds and streak shields
- **Duels** — Challenge friends to competitive quiz battles with real-time scoring
- **AI Chat** — Conversational tutor with RAG-enhanced responses using your own study content
- **History & Favorites** — Browse, filter, and bookmark all generated content

## ⚙️ Setup & Run

### Prerequisites
- Java 25+
- Apache Maven
- Apache Tomcat 10
- Supabase account (PostgreSQL)
- OpenAI API key

### Steps

1. **Clone the repo**
   ```bash
   git clone https://github.com/ErickaA3/ProyectoTri2.git
   cd ProyectoTri2
   ```

2. **Configure environment**  
   Set your Supabase connection string and OpenAI API key in the appropriate configuration files.

3. **Build with Maven**
   ```bash
   mvn clean package
   ```

4. **Deploy to Tomcat**  
   Copy the generated `.war` file from `target/` to Tomcat's `webapps/` directory, or use your `deploy.bat` script.

5. **Access the app**  
   Open `http://localhost:8080` in your browser.
